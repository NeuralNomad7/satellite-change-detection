# Data: Sentinel-2 Imagery for Change Detection

## Recommended Datasets

### LEVIR-CD (Primary)

The LEVIR-CD dataset is the standard benchmark for building change detection. It contains 637 pairs of high-resolution (0.5m/px) Google Earth images at 1024x1024 pixels, with pixel-level binary change annotations focused on building construction and demolition.

**Download**: https://justchenhao.github.io/LEVIR/

**Split**: 7120 / 1024 / 2048 non-overlapping 256x256 patches for train / val / test (standard split from the original paper).

### OSCD (Onera Satellite Change Detection)

14 pairs of Sentinel-2 multispectral images (13 bands) covering urban areas worldwide. Change labels indicate urban growth. This dataset is smaller but uses actual Sentinel-2 data with all spectral bands.

**Download**: https://rcdaudt.github.io/oscd/

### WHU Building Change Detection

Covers a single large area (32507x15354 pixels at 0.075m resolution) with aerial imagery from 2012 and 2016. Good for testing generalization on very high resolution data.

**Download**: https://study.rsgis.whu.edu.cn/pages/download/

## Sourcing Your Own Sentinel-2 Data

### Copernicus Open Access Hub

1. Register at https://scihub.copernicus.eu/
2. Use the map interface to select your area of interest
3. Filter by:
   - Platform: Sentinel-2
   - Product type: S2MSI2A (Level-2A, atmospherically corrected)
   - Cloud cover: < 10%
4. Download two scenes of the same area from different dates

### Using the Copernicus Data Space API

```python
# Example: search for Sentinel-2 tiles programmatically
import requests

url = "https://catalogue.dataspace.copernicus.eu/odata/v1/Products"
params = {
    "$filter": (
        "Collection/Name eq 'SENTINEL-2' "
        "and ContentDate/Start gt 2024-01-01T00:00:00.000Z "
        "and ContentDate/Start lt 2024-06-01T00:00:00.000Z "
        "and OData.CSC.Intersects(area=geography'SRID=4326;"
        "POINT(-122.4194 37.7749)') "
        "and Attributes/OData.CSC.DoubleAttribute/any("
        "att:att/Name eq 'cloudCover' and att/Value lt 10.0)"
    ),
    "$top": 10,
}
response = requests.get(url, params=params)
```

### Band Information

Sentinel-2 provides 13 spectral bands at varying resolutions:

| Band | Name            | Wavelength (nm) | Resolution (m) | Use Case                    |
|------|-----------------|------------------|-----------------|-----------------------------|
| B01  | Coastal aerosol | 443              | 60              | Atmospheric correction      |
| B02  | Blue            | 490              | 10              | Land/water discrimination   |
| B03  | Green           | 560              | 10              | Vegetation vigor            |
| B04  | Red             | 665              | 10              | Vegetation classification   |
| B05  | Veg Red Edge 1  | 705              | 20              | Vegetation stress detection |
| B06  | Veg Red Edge 2  | 740              | 20              | Leaf area index             |
| B07  | Veg Red Edge 3  | 783              | 20              | Canopy water content        |
| B08  | NIR             | 842              | 10              | Biomass estimation          |
| B8A  | Narrow NIR      | 865              | 20              | Water vapor                 |
| B09  | Water vapor     | 945              | 60              | Atmospheric correction      |
| B10  | SWIR (cirrus)   | 1375             | 60              | Cloud detection             |
| B11  | SWIR 1          | 1610             | 20              | Soil/vegetation moisture    |
| B12  | SWIR 2          | 2190             | 20              | Snow/ice discrimination     |

For change detection, the most useful bands are B02-B04 (visible), B08 (NIR), and B11-B12 (SWIR). The common practice is to resample all bands to 10m resolution and stack them.

## Data Preparation

After downloading, organize your data like this:

```
data/
├── raw/
│   ├── train/
│   │   ├── A/          # Pre-change images
│   │   ├── B/          # Post-change images
│   │   └── label/      # Binary change masks
│   ├── val/
│   │   ├── A/
│   │   ├── B/
│   │   └── label/
│   └── test/
│       ├── A/
│       ├── B/
│       └── label/
└── processed/          # Generated by data pipeline
```

The data loader in `src/data_loader.py` handles patching, normalization, and augmentation automatically once data is in this structure.

## Creating Change Labels

If working with your own Sentinel-2 scenes (not a pre-labeled dataset), you can create change labels using:

1. **QGIS**: Free GIS software. Load both scenes, digitize changed areas as polygons, rasterize to create a binary mask.
2. **Label Studio**: Open-source labeling tool with image comparison support.
3. **Semi-automatic**: Compute NDVI difference between dates, threshold it, then manually refine the resulting mask.

NDVI (Normalized Difference Vegetation Index) is computed as:
```
NDVI = (NIR - Red) / (NIR + Red) = (B08 - B04) / (B08 + B04)
```

Large NDVI drops between dates often indicate deforestation or construction.
